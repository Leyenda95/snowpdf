# Keyboard shortcuts

Tool keys do nothing while you are typing in a text field.

## Editor tools

| Key | Action |
|---|---|
| V | Select and fill forms |
| H | Hand (pan) |
| T | Add text |
| E | Edit existing text (click to edit, drag to move, right-click for the object menu; edited text is plain page content in other tools) |
| I | Add image |
| S | Sign |
| R | Rectangle |
| O | Ellipse |
| L | Line |
| A | Arrow |
| D | Freehand drawing |
| M | Highlight |
| W | Whiteout |
| X | Redact (really remove) |
| B | Magic eraser |
| K | Check mark |
| Esc | Cancel placement, clear selection, or return to Select |

## Editing and file

| Shortcut | Action |
|---|---|
| Ctrl+Z | Undo |
| Ctrl+Y / Ctrl+Shift+Z | Redo |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as... |
| Ctrl+C / Ctrl+X / Ctrl+V | Copy / cut / paste |
| Ctrl+D | Duplicate the selection |
| Ctrl+A | Select every object on the current page (edited original text excluded) |
| Del / Backspace | Delete the selection |
| Arrow keys | Move the selection (Shift for larger steps) |

## View and navigation

| Shortcut | Action |
|---|---|
| Ctrl++ (or Ctrl+=) | Zoom in |
| Ctrl+- | Zoom out |
| Ctrl+0 | Zoom to 100% |
| Ctrl+F | Open the search panel |
| Page Up / Page Down | Previous / next page |
| Home / End | First / last page |
